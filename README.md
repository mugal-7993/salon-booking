# Bloom Salon – Booking & Membership (Next.js 14)
Run locally: `npm install && npm run dev` → http://localhost:3000

Deploy (Vercel): push to GitHub → vercel.com/new → import repo → Deploy (no settings needed).
Or CLI: `npx vercel --prod`

Note: data is stored in the browser (localStorage) as a demo. For real use, add a database (e.g. Supabase/Postgres) and auth (NextAuth/Clerk).
